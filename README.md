# P EIGHT — DJ Profile Website

> Official profile page for **P Eight** (Hoàng Phúc) — Open Format DJ from Nha Trang, Vietnam.

## 🎧 About

Dark, cinematic one-page DJ profile inspired by [Solomun](https://solomun.webflow.io/). Built with pure HTML/CSS/JS — no frameworks, no dependencies (except Google Fonts).

## 🗂 Structure

```
DJ_P_Eight/
├── index.html          ← Main profile page
├── IMAGE_/             ← Artist photos
├── PERFORMANCE/        ← Stage & club shots
├── POSTER/             ← Event posters
├── LOGO_/              ← Logo files (black & white)
├── MIXTAPE_/           ← Audio mixes (.wav)
├── PRESSKIT/           ← Press kit PDF
├── RECAP/              ← Recap videos
└── background/         ← Background assets
```

## ✨ Features

- **Hero** — Full-screen cinematic photo with parallax scroll
- **Ticker** — Animated scrolling genre/name marquee
- **About** — Bio with editorial layout
- **Gallery** — Bento grid with lightbox
- **Venues** — Animated list of clubs & stages performed at
- **Mix Player** — Embedded audio players with waveform animation
- **Posters** — Horizontal scroll event poster carousel
- **Booking** — Contact section with phone, email & social links
- Custom cursor, scroll-reveal animations, mobile responsive

## 📍 Deployment (GitHub Pages)

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site will be live at `https://<username>.github.io/<repo>/`
